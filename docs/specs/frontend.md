# 素材制作工作台前端规格

2026-11-11 · v1.2

领域用语以 [CONTEXT.md](../../CONTEXT.md) 为准。页面行为承接[项目总规格](../../outputs/素材制作工作台-开发规格.md)和已确认的前端 Grill Me 决定。请求和响应以[后端规格](./backend.md)为准。

## 问题陈述

用户需要看清每张图片是否已成为可提交的素材、每次提交是否已受理，以及每项制作任务当前的状态。连续提交、替换选图、刷新、切换演示身份或遇到网络异常时，旧请求的响应不应改变用户正在操作的上传位或当前身份的任务。

## 解决方案

提供模板列表、模板详情和个人历史三个页面。顶部展示当前演示身份并提供切换入口。模板详情逐位上传素材，受理后在当前页展示任务卡片。详情和个人历史共用任务卡片与跟踪规则，从 Java 恢复制作任务。上传、提交、任务状态、进度查询异常和结果图加载分别反馈。

## 用户故事与验收条件

1. **FE01 · 筛选模板并返回原分类。** 作为用户，我希望从详情返回时保留筛选，从而继续浏览同一分类。

   **验收**　列表从 Java 获取分类、标题和封面。选择分类后 URL 反映该筛选，刷新、分享链接及从详情返回都可恢复筛选。选择「全部」恢复完整列表。加载中、空结果与请求失败分别展示，失败时可重试。
2. **FE02 · 按模板准备图片。** 作为用户，我希望在上传前理解素材要求，从而减少无效尝试。

   **验收**　详情显示标题、描述、封面及所需图片数、支持格式、字节和像素限制，并渲染对应数量的上传位。模板 404 显示不存在并提供返回列表入口。其他加载错误显示重试。
3. **FE03 · 在当前位置选择或切换演示身份。** 作为用户，我希望知道当前使用哪个身份，并能在当前位置选择 A 或 B。

   **验收**　顶部「账户设置」入口显示当前身份。右上角显示「账户设置」文字。弹窗显示 Java 确认的身份、账户 ID、A/B 选择和个人历史入口，支持键盘打开、Escape 关闭及焦点返回。未选择时仍可浏览模板。上传区域和个人历史就地提示选择身份，选择完成后留在当前页。切换期间停用受保护操作，清理旧身份的上传位和任务数据，旧请求晚到时不填入新身份的页面。
4. **FE04 · 独立上传、替换和移除图片。** 作为用户，我希望独立处理每个上传位，从而可以只重试有问题的图片。

   **验收**　选图后显示预览和上传反馈。前端先检查浏览器提供的图片格式及文件体积，实际内容和像素由 Java 校验。若照片甲替换为照片乙后乙上传失败，显示乙的预览与失败原因，提交保持禁用，直到该位置就绪。其他就绪位置不受影响。替换、移除后忽略旧上传响应。
5. **FE05 · 提交后继续留在详情页。** 作为用户，我希望拿到任务卡片后继续编辑当前选图，从而连续创建制作任务。

   **验收**　有演示身份且所有必填上传位就绪时才可提交。提交中禁用重复点击。收到 202 后结束「提交中」，在相邻任务区展示独立任务卡片并保留上传位。再次提交使用当时有序的素材 ID，并展示另一项任务。
6. **FE06 · 查清提交结果未知。** 作为用户，我希望核对是否已受理，同时保留当前选图。

   **验收**　提交超时、断连或收到无法确认受理结果的服务错误时，页面提示查看个人历史。入口标明在新标签页打开，原详情页保留选图。前端不自动重发提交。Java 明确拒绝时显示对应的可操作错误。
7. **FE07 · 并行跟踪多项制作任务。** 作为用户，我希望各项任务独立更新，从而看清等待、处理和完成的分别情况。

   **验收**　两项任务的状态、制作阶段、结果和错误按任务 ID 分开。第一项进度查询超时或收到 503 时，保留原状态和阶段并显示「暂时无法更新进度」，第二项仍可更新。可点「立即重试」，下一轮也自动重试。成功获取进度后清除提示。已达终态的任务停止自动查询。
8. **FE08 · 恢复会话或核对不可见的任务。** 作为用户，我希望失效会话和不可见任务得到明确处理，从而可以找回自己的记录。

   **验收**　当前会话的受保护请求收到 401 时，停止旧会话跟踪、清除其页面数据并提示重选身份。单项任务收到 404 时，停止对它自动查询并核对当前会话及相关任务列表，根据列表决定保留或移除卡片。旧会话的 401 或 404 晚到时不会清理新身份数据。
9. **FE09 · 刷新后恢复制作任务。** 作为用户，我希望回到页面时继续跟踪已经受理的任务。

   **验收**　个人历史从 Java 恢复所有已受理任务，并按服务端顺序展示创建时间、模板、任务状态和阶段。模板详情恢复当前模板的历史和未完成任务。刷新或离开后重新进入，上传位为空。离开相关页面后旧查询无法回写，无待跟踪任务时停止自动查询。
10. **FE10 · 查看结果和失败原因。** 作为用户，我希望直接在卡片中查看制作结果或制作失败原因。

    **验收**　详情和个人历史使用相同的卡片。成功卡片直接预览结果图，注明「上传素材拼贴」或「模拟制作 · 示例结果」。图片加载失败时仍显示制作成功，图片区域显示「预览暂不可用」及重试入口。制作失败时显示服务端提供的失败阶段和原因。
11. **FE11 · 在小屏和键盘下操作。** 作为用户，我希望主要流程在小屏和键盘下可用。

    **验收**　小屏下内容按阅读和操作顺序纵向排列。身份切换、分类、选图、上传位操作、提交和重试可使用键盘。焦点可见，图标和文件输入有可理解的标签，上传和任务状态用文字表达。

## 实现决策

### 页面与身份

| 路由 | 数据与界面 |
| --- | --- |
| `/` | 调用模板列表。用 URL 的 `category` 记录分类，「全部」时省略该参数。进入详情时携带来源分类供返回入口使用。 |
| `/templates/[id]` | 调用模板详情。身份可用后加载该模板的所有制作记录。上传区与任务区分开，本次页面已经展示的卡片在变为终态后仍留在任务区。 |
| `/history` | 身份可用后加载个人历史，保留服务端的稳定倒序。显示加载、空记录、失败与重试。 |

- 顶部读取 `GET /api/session`，通过 `POST /api/session` 选择或切换身份。后续请求走同源 API，由 Java 会话 Cookie 确定归属。切换开始后取消旧工作并使旧响应失效。切换结果不明确时重新读取会话，再按实际身份加载数据。
- 受保护请求的响应只有在页面与会话仍匹配时才能更新状态。当前会话收到 401 时进入待选身份。公开模板区域仍可使用。
- 按附件 UI-01–03 使用深色界面。列表的分类位于封面网格上方，标题叠在竖版封面底部。详情桌面为左右两栏，左侧约三分之一放模板、上传位和制作按钮，右侧为任务卡片网格。小屏将任务区移到制作区下方。个人历史复用卡片。按 R-10 配图组织账户设置弹窗，展示当前演示身份和选择入口。

### 上传位与提交

- 上传位状态为「空、上传中、就绪、上传失败」。每个位置独立持有当前选图、预览和上传结果。替换或移除时取消旧请求并使旧回调失效，同时释放旧预览资源。
- 详情读取 `requiredImageCount`、`acceptedMimeTypes`、`maxFileSizeBytes` 和 `maxImagePixels`。明确不匹配的文件类型或过大的文件在前端提示。浏览器无法识别格式时以 Java 校验结果为准。像素和实际图片内容由 Java 判定。
- 上传调用 `POST /api/assets`，成功返回素材 ID 后该位置才就绪。重试只操作当前选图和当前上传位。服务器错误原因优先用于对应位置的提示。
- 提交调用 `POST /api/tasks`，按上传位顺序取当前素材 ID。提交请求状态与任务卡片状态分开。收到 202 即加入卡片并跟踪任务。保留上传位供再次提交。刷新、离开详情或切换演示身份时清空上传位。任务受理前校验被明确拒绝时，保留可以继续使用的选图。
- 提交结果未知时展示个人历史入口并保留原页，允许用户核对后自行决定是否再次提交。

### 任务卡片与跟踪

- 同一页面内以任务 ID 管理卡片。以 `GET /api/tasks` 加载列表。详情传当前 `templateId`，个人历史读取完整列表。随后仅查询处于 `PENDING` 或 `PROCESSING` 的任务。
- 默认每 2 秒触发一轮查询。同一任务至多一个在途查询，手动重试复用在途请求。各任务独立推进，单项请求慢或失败时不阻塞其他任务。
- 超时、网络错误和暂时服务不可用时，保留该任务上次已知的状态和制作阶段，标记进度查询异常，支持下一轮自动重试及立即重试。收到服务端 `FAILED` 才展示制作失败。
- 单项任务查询返回 404 时，将它移出自动查询集合。核对实际会话及相关任务列表后合并结果。已不在该页面范围内的任务移除。详情使用该模板的完整列表进行核对。核对请求本身暂时失败时提示可手动重新加载，同一 404 不触发无休止的自动核对。
- `SUCCEEDED` 与 `FAILED` 终止该项轮询。没有待跟踪任务时停止定时器。离开页面或切换身份时取消在途请求、清理计时器，并检查晚到响应是否还属于当前页面与会话。
- 卡片显示「等待处理、处理中、成功、失败」，按服务端制作阶段显示「素材检查、模拟生成、结果整理」。制作结果的预览加载独立于任务状态。重试图片时只重新加载图片。

## 测试决策

优先在页面交互和同源请求边界断言用户可见行为。用受控请求和虚拟时钟复现时序，避免依赖真实网络和等待时长。

| 测试入口 | 最先验证的行为 |
| --- | --- |
| 列表与详情 | 切换分类、URL 恢复、返回列表、单图与双图上传位、模板 404 与普通加载失败的区分。覆盖 FE01–FE02。 |
| 身份、上传及提交 | 让上传响应晚于替换、移除或身份切换，验证响应无法恢复旧状态。验证替换失败禁用提交、保留有序素材 ID、202 后继续编辑、提交结果未知时新标签页及无自动重提。覆盖 FE03–FE06。 |
| 任务跟踪 | 两项任务中一项超时或收到 503，另一项继续更新。验证恢复后清除提示、终态停查、无任务时停表、旧 401 或 404 不影响新身份、当前任务 404 触发一次核对。覆盖 FE07–FE09。 |
| 制作结果与可用性 | 验证成功结果图、失败阶段、图片预览失败与重试。手动检查小屏、键盘焦点及主要操作。覆盖 FE10–FE11。 |

前端首条 TDD 测试验证两项任务中一项遇到进度查询异常时，另一项仍能更新。随后加入终态停查和旧会话响应隔离。CI 执行前端测试、lint、类型检查和构建。

## 范围外

持久保存未提交选图、跨页素材库、制作结果下载和删除、失败任务重跑、自动重发提交、页面内模拟控制区及单独的移动端设计均在首版范围外。

## 交付说明

README 提供从模板筛选到身份切换、上传、连续提交、刷新和结果预览的演示路线。指定失败阶段与调整耗时沿用后端规格的命令方式。
